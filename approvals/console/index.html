How it decides

The model is never the gate.

Decider measures; plain Python decides from its two answers; a person confirms what it pauses. Before Decider, a read outside secret paths proceeds and arguments that look like a credential pause.

If Decider does not answer (GPU asleep, no capacity), the call pauses fail-closed with no score. Source: src/lachesis/policy.py.

First match wins

  1. R1Score under 0.70, any classPause
  2. R2Exfiltration, 0.70 or aboveDeny
  3. R3Destructive write, untrusted input acted on, confused deputyPause
  4. R4A risk class Decider does not knowPause
  5. R5Benign, not grounded in what the user saidGuide
  6. R6Benign, grounded, 0.70 or aboveProceed
