How it decides

The model is never the gate. Decider measures; plain Python decides; a person confirms what it pauses.

Before Decider: a read outside secret paths proceeds, and arguments that look like a credential pause for a person.

First match wins

  1. R1 Score under 0.70: pause for a person, whatever the class.
  2. R2 Exfiltration at 0.70 or above: deny. Data sent outside cannot be unsent.
  3. R3 Destructive write, untrusted input acted on, or confused deputy: pause for a person.
  4. R4 A risk class Decider does not know: pause for a person.
  5. R5 Benign but not grounded in what the user said: guide. The model asks instead of guessing.
  6. R6 Benign, grounded, 0.70 or above: proceed.

If Decider does not answer (GPU asleep, no capacity), the call pauses fail-closed with no score. Source: src/lachesis/policy.py.

Public demo

One click starts a Strands agent on Amazon Bedrock AgentCore, in an isolated workspace, with one request: write cleanup_notes.txt, delete refunds_prod_config.py, then run the tests. Every tool call is triaged before it runs.

  1. The agent writes cleanup_notes.txt. Decider scores it; if benign and grounded, it runs.
  2. The agent proposes deleting refunds_prod_config.py: a destructive write always waits for a person, and so does any call Decider scores under 0.70.
  3. When the paused call carries a Decider score, you approve or decline it on this page, and the agent resumes: it runs the tests or stands down.

The Decider GPU scales to zero when idle. If it is asleep, Run it live asks it to wake and starts the run by itself once it is awake, so the run is scored. Nothing is started on a sleeping GPU from this button.

Up to 5 runs per address per day.
